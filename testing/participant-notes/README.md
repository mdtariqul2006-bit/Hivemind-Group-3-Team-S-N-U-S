# Participant notes

One file per usability test session, written up from
[`testing/test-script.md`](../test-script.md), right after the session while
it is fresh.

Use a participant ID such as P01, never the participant's real name, matching
the convention already used in `research/transcripts/`. Since this reuses the
same ID space as the Week 1 research interviews, prefix the filename with the
tester's name so IDs do not collide, for example
`Asan_P01_2026-08-05_UsabilityTest.md`.

Copy [`template.md`](template.md) for each new session.
