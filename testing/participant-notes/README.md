# Participant notes

One file per usability test session, filled in from `TEMPLATE.md` right after
each session while it's fresh.

Name files using the same format as `research/transcripts/`, from the
handbook:

```
GroupName_StudentName_PXX_YYYY-MM-DD_UsabilityTest.md
```

For example `Group3_SNUS_Asan_P01_2026-08-04_UsabilityTest.md`. Use a
participant ID such as P01, never the participant's real name or any contact
detail, in the filename or inside the file.

Owned by the UX Research Lead (Asan Limbu).
