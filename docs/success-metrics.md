# Success metrics

3 to 5 simple measures the group will test the prototype against in Week 4. To be defined once the hypotheses are written.

Owned by the UX Research Lead (Asan Limbu), with feasibility input from the Technical/Feasibility Lead (Anita Rahman).

Examples from the handbook:

- Can users understand what to do next within the first minute.
- Can users find key onboarding information within a few clicks.
- Can users identify who to ask for help.
- Do users feel more confident after viewing their onboarding progress.
